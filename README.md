# MountainLake 🌄

**MountainLake** is an Unreal Engine 5.7 project showcasing a serene natural outdoor scene featuring a calm riverside, a rustic wooden cabin, and distant snow-covered mountains. The environment combines procedural generation with Nanite technology for realistic foliage and landscapes.
